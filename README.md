# Internet Programming

This repository contains a collection of front-end web development experiments focused on building interactive booking and management systems using HTML, CSS, and JavaScript.

## Projects Included

### 1. Library Management Website
A simple library management interface for browsing books, managing available copies, and handling library-related actions.

- Technologies: HTML, CSS, JavaScript
- Folder: `Experiment 1: Library Management Website`

### 2. Hotel Room Booking
A hotel booking webpage that allows users to view room options and simulate booking interactions.

- Technologies: HTML, CSS, JavaScript
- Folder: `Experiment 2: Hotel Room Booking`

### 3. Bus Ticket Booking
A bus reservation interface for selecting routes and completing reservation-related tasks.

- Technologies: HTML, CSS, JavaScript
- Folder: `Experiment 3: Bus Ticket Booking`

## Tech Stack

- HTML for page structure
- CSS for styling and layout
- JavaScript for interactivity and form logic

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Sundar1207/Internet-Programming.git
   ```
2. Open any project folder in your browser.
3. Open the `index.html` file for that project.

Example:
```bash
cd "Experiment 1: Library Management Website"
# then open index.html in a browser
```
